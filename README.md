# Tema SDDM Xbox 360 Metro (Qt6)

Tema personalizado para a tela de login **SDDM (Qt6)** inspirado na dashboard **Metro (2011) do Xbox 360**, desenvolvido para **Q4OS / Debian / KDE Plasma**.

## Recursos Incluídos
- **Interface Xbox 360 Metro:** Cartão de perfil com borda escura, Gamerscore personalizado, seletor suspenso de ambiente de sessão (X11 / Wayland) e botões inferiores estilo controle (A, X, Y).
- **Animações Suaves (1s):** Entrada com deslize vertical nos blocos centrais e Fade In no cabeçalho e rodapé.
- **7 Efeitos Sonoros Originais:** Sons dedicados ao iniciar a tela, passar o mouse nos botões, abrir o menu de sessão, acertar ou errar a senha, reiniciar e desligar.
- **Suporte Nativo a Controles (Xbox e PS4 DualShock 4):** Navegue e faça login, reinicie ou desligue usando o controle antes mesmo de entrar no sistema.
- **Som de Boas-Vindas no KDE Plasma:** Toca automaticamente ao entrar na área de trabalho.

## Instalação Rápida
```bash
git clone https://github.com
cd sddm-xbox360-metro
chmod +x instalar.sh
./instalar.sh
```
